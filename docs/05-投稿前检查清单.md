# 投稿前检查清单

按顺序过一遍。**任何一项标红，就不要点 submit。**

---

## A. 选刊与文章类型

- [ ] 目标期刊、文章类型（Article / Report / Brief Communication / Methods）已明确。
- [ ] 读了该刊最近 6 期的 3–5 篇同类文章，确认篇幅、图数、结构惯例。
- [ ] 确认不是"以子刊规则套正刊"或反之。
- [ ] 确认没有同时投递（duplicate submission），预印本政策已核对。
- [ ] 确认作者列表、顺序、通讯作者已获全体同意。

## B. 核心论证

- [ ] 能用**一句话**说清本文的贡献（不是"我们研究了…"）。
- [ ] 每个主 claim 都有对应的图/表/统计，且一一对应。
- [ ] 每个 claim 的强度与证据匹配（相关 ≠ 因果；体外 ≠ 体内；模型 ≠ 人类）。
- [ ] 至少排除了一个最强的替代解释。
- [ ] 局限性（limitations）单独写出，具体到模型/样本/技术/时间尺度。
- [ ] 结论没有超出数据边界；摘要最后一句尤其检查。

## C. 结构与写作

- [ ] 标题符合该刊字符数限制；无缩写、无 hype、无 "novel/study on"。
- [ ] 摘要符合该刊字数与结构（Nature summary / Cell summary / Science abstract）。
- [ ] Introduction 最后一段明确写出 gap 和本文做了什么。
- [ ] Results 小标题是 claim，不是方法名。
- [ ] 每段只做一件事；段首句是主题句。
- [ ] Discussion 不重复 Results，不写成综述。
- [ ] 全文术语、缩写、单位、基因/蛋白命名一致。
- [ ] 时态正确：Results 用过去时；结论/普遍事实用现在时。
- [ ] 没有 AI 味：无 "delve into"、"it is worth noting"、"plays a crucial role" 堆砌。

## D. 图表

- [ ] 每个图都有明确的"要证明什么"，且正文按顺序引用。
- [ ] 面板编号连续；每个面板都被正文提到。
- [ ] 图注以一句 title sentence 开头；≤250 词（Nature）。
- [ ] 每个面板有 n、误差棒定义、统计检验、尺度 bar、单位。
- [ ] 颜色色盲安全；灰度打印仍可区分。
- [ ] 字体在最终缩放下 ≥6–7 pt；线宽足够。
- [ ] 分辨率：照片 ≥300 dpi；线条/组合图 ≥600–1000 dpi（按刊要求）。
- [ ] Western blot 有原始条带、分子量、上样量、重复数。
- [ ] 显微镜图有 scale bar、通道、z-stack 说明。
- [ ] Graphical abstract 与摘要一致（Cell 必查）。

## E. 统计

- [ ] 每个检验写明：检验名、n、单/双尾、配对与否、校正方法。
- [ ] 报告效应量 + 95% CI，不只报 P。
- [ ] P 值精确到小数点后两位（除非 <0.001）。
- [ ] 误差棒明确是 SD / SEM / 95% CI，全文统一。
- [ ] 生物学重复 vs 技术重复写清楚；n 是生物学重复数。
- [ ] 样本量如何确定（power analysis 或先验说明）。
- [ ] 多重比较已校正（Tukey / Bonferroni / FDR）。
- [ ] 随机化、盲法、排除标准写明。
- [ ] 报告规范：CONSORT / PRISMA / STROBE / ARRIVE / TRIPOD 对应项已填。

## F. 引用与诚信

- [ ] 每条参考文献真实存在；DOI/PMID 可解析。
- [ ] 没有 retracted 论文被当作有效证据。
- [ ] 引用语境与原文结论一致（没有断章取义）。
- [ ] 自引比例合理；没有引用堆砌。
- [ ] 图片没有不当裁剪、拼接、重复使用；原图可提供。
- [ ] 数据没有选择性报告；阴性结果有交代。
- [ ] 文本与已发表作品没有重叠（self-plagiarism 已检查）。
- [ ] AI 使用已按期刊政策披露；AI 不署名。

## G. 声明与材料

- [ ] Data Availability：仓库/accession/DOI/限制条件。
- [ ] Code Availability：核心代码仓库、版本、许可证。
- [ ] Author contributions：按 CRediT 或该刊格式，具体到人。
- [ ] Competing interests：无也要写 "none"。
- [ ] Funding：只写真正支持该工作的 grant。
- [ ] Ethics：伦理批号、知情同意、动物伦理、临床注册号。
- [ ] Acknowledgements：不感谢匿名审稿人；不写溢美之词。
- [ ] 通讯作者信息、单位、邮箱、ORCID 已核对。

## H. 文件与系统

- [ ] 按该刊要求合并/拆分文件（Nature 初始投稿可正文+图一个 PDF ≤30 MB）。
- [ ] 行号、页码、双倍行距、12 pt Times New Roman（如该刊要求）。
- [ ] 图注与图同页（Nature 初始投稿）。
- [ ] 补充材料有目录、编号、逐项正文引用。
- [ ] Cover letter 简洁：重要性、创新点、适合该刊的理由、保密信息。
- [ ] 推荐/回避审稿人名单（如该刊要求）。
- [ ] 所有文件用统一命名：`FirstAuthor_Year_Journal_Fig1.pdf`。
- [ ] 提交系统里填的摘要与稿件摘要完全一致。
- [ ] 最终 PDF 自己从头到尾读一遍（尤其是公式、上下标、特殊字符）。

---

## 提交前的最后三问

1. **如果审稿人只读摘要和第一张图，他能不能准确说出我发现了什么？**
2. **我最想隐藏的那个弱点，审稿人会不会一眼看到？我有没有正面处理它？**
3. **这篇文章如果被拒，最可能是因为哪一条？我现在能不能补？**

三个问题都答得出来，再提交。
