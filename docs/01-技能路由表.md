# 技能路由表

共 44 个技能：42 个来自上游权威仓库，2 个是本整合包自带的调度器。

**读法**：先看"层"，再看"什么时候用"。不要一次加载多个技能；调度器会按阶段只叫一个。

| ID | 作用 | 什么时候用 |
|---|---|---|

## 典型组合

**从零写一篇 Nature 子刊论文**
`journal-pipeline` → `literature-review` → `claim-source-verification` → `manuscript-optimizer` → `write-scientific-manuscript` → `sciwrite` → `nature-polishing` → `figure-planner` + `scipilot-figure` → `citation-verifier` → `paper-reviewer` → `rebuttal-response`

**已有草稿，只差投稿**
`journal-pipeline`（Gate 1/2/5/6）→ `journal-adapt` → `stats-reporting-audit` → `citation-verifier` → `submission-audit`

**CFD 论文**
`cfd-fluent-pipeline` → `fluent-cfd` → `uncertainty-and-units` → `scipilot-figure` → `journal-pipeline`（Gate 3 起）

**只有实验数据，没有仿真**
`openpiv` / `statistical-analysis` → `scipilot-figure` → `journal-pipeline`
